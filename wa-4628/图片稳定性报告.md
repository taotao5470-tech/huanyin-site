## 🧬 去重分析

按 MD5 hash 跨 SPU 比对：

| 类型 | 数量 |
|------|------|
| 独立 hash | 461 |
| 仅出现在 1 个 SPU | 343 |
| 跨多个 SPU 共享 | 118（合理：同一张图可能同时属于球衣主/客场） |
| 跨 SPU 副本 | 119 |

跨 SPU 共享是预期行为——例如一张"巴西国家队历史合影"可能既出现在主场球衣详情页、也出现在客场球衣详情页。这不是 bug。
